# 📚 StudyBuddy AI

### Your Personal AI Study Partner

StudyBuddy AI is an AI-powered study assistant that helps students
turn their study material into revision notes and practice questions.

## ✨ Features

- 🤖 AI-powered revision summaries
- 📂 Upload PDF study materials
- 📝 Generate multiple-choice quizzes (MCQs)
- 🎯 Automatic quiz scoring
- 💡 Answers with explanations
- 📊 Student Progress Dashboard
- 📈 Quiz performance chart
- 📄 Downloadable revision notes in PDF format

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini AI
- ReportLab
- PyPDF
